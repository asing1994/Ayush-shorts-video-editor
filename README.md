# Ayush Shorts Editor

Ayush Labs desktop software for creating YouTube Shorts.

## Requirements

- Node.js 20+ recommended
- Windows 10/11

## Run

```bash
npm install
npm run dev
```

The Electron desktop editor will open.

## Editing

- Import multiple MP4/MOV/MKV/WebM/AVI clips into one sequential timeline
- Scrub and preview clips, with automatic H.264 preview conversion when needed
- Trim clip in/out points, split at the playhead, reorder, and delete clips
- Add and mix one background music track with adjustable volume
- Add a positioned text overlay and choose fit or fill framing
- Save and reopen `.ayushshorts` project files
- Export a combined 1080 × 1920, 30 fps H.264/AAC MP4 using bundled FFmpeg

Speech-to-text captions, animated caption styles, keyframed motion, and AI-assisted editing are not included in this local release.
